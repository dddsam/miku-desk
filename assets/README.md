# 自定义桌宠素材

公开源码不附带角色视频和图标。将自己制作或有权使用的素材放入本目录，使用以下名称：

| 文件名 | 使用场景 |
| --- | --- |
| `miku_standby.mp4` | 待机循环 |
| `miku_work_happy.mp4` | 开心工作循环 |
| `miku_work_angry.mp4` | 生气工作循环 |
| `miku_not_understand.mp4` | 方案被驳回或系统长时间无操作 |
| `miku_finishwork.mp4` | 任务完成，播放一次 |
| `icon.png` | 托盘图标 |

建议动作视频使用无音轨或静音、正方形画面。当前界面会圆形裁切并静音播放；720 × 720 的 H.264 MP4 已在原项目中验证过。图标可使用带透明背景的 PNG。

这些文件名是程序约定，不要求视频中的角色一定是 Miku。原项目使用者可以从自己保留的 v0.1.2 源码包 `assets/` 文件夹复制六个文件，用于本机运行。

在项目根目录执行 `npm run check:assets` 可检查文件是否存在。此检查不验证编码和素材许可。

Git 默认忽略上述视频和图标，避免把本地素材意外发布。如果希望公开分发自己的素材，需要明确其来源、作者和许可，并相应调整忽略规则。根目录 MIT 许可证仅覆盖本仓库的代码和文档。
